## Merge policy

Main's ruleset requires one approving review from a person after this
review, so your APPROVE alone does not merge a change here.

## Tracker

This repository holds the organization's secrets and the bot's token, and its
`.github/` (the dispatch bounds, the workflows and the poll) decides which runs
receive them. For a change there, name each secret or token a changed file
now reaches and from which trigger.
