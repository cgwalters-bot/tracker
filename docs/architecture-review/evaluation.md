## Scoring rubric

Deduplicate findings by root cause. Match only if the finding identifies the
same design concern and affected component/evidence at the frozen revision as a
linked operator comment. Similar pattern IDs alone do not match. A question
matching a question/tradeoff counts only in a separate question/tradeoff
stratum, never as a caught defect. Report one concern unit caught at most once.
Classify comments not supported by the historical packet as unscorable with a
reason, not as misses. Unmatched findings are not automatically false:
independently audit their evidence and report supported/unsupported/unresolved
over the number audited. Operator feedback is not an exhaustive bug oracle.
