injection), and feedback/later fixes leaking into a retrospective result. The
single mechanism is an explicitly supplied, read-only input packet: reviewed
material is data, not authority. It has finite input/output limits in the prompt.
This is procedural separation, not a new security sandbox. Nothing invokes it
automatically; there is no new caller option to configure.
