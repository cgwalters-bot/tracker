The standalone setup script is copied/chmodded by runner-setup.py, not run
as root. It requires the wrapper's `SOAK_MINUTES`, copies its loop into the
agent home and writes exactly two session steps: the shipped first execute
redaction canary, then one execute loop. There are no application writes or
scripted comments. The loop GETs `https://api.github.com/zen` immediately and
each minute, writes UTC/monotonic elapsed/HTTP status/transport failure with
synchronous stdout writes, and keeps going on HTTP or transport failure.
Each request has a 10-second connect and at most 20-second total deadline,
bounded further by the remaining duration. It uses curl's proxy/CA settings,
does not follow redirects and discards response bodies. At duration end it
writes only the required outcome and one noop. HTTP failures are diagnostic
observations, not a reason to cut the soak short or mark survival as failed.

`just test-soak` checks rejected inputs, config parity, exact canary,
the blocked fake-only route, failure continuation and an accelerated short
smoke. This is not a hosted secure-host/redaction upload or no-inference
end-to-end test. A plain one-minute local loop can be run outside a checkout
with `HOME` pointing to a disposable directory; it writes only `HOME/out`.
