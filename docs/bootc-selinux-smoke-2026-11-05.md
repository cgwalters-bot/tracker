## Remaining evidence

bounded invocation of each smoke. Increasing compilation time alone would not
resolve the missing libvirt/tmt setup. This run did not explore a user-local
libvirt/QEMU stack or a containerized replacement for the workflow's host stack.
No claim is made that such alternatives are impossible, or that KVM itself
failed. The observed limits are setup availability and the chosen attempt bounds.

environment, complete a default-feature build against an identified main SHA,
